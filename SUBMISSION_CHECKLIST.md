# Final submission checklist

Preparation is complete only as a runnable draft; this checklist concerns the later graded submission.

- [ ] Confirm class Kaggle data, allowed splits, rules and submission format in the enrolled account.
- [ ] Review/explain all architectures, code and hyperparameters personally.
- [ ] Complete full runs on recorded hardware; preserve raw logs, configuration and data/source hashes.
- [ ] Execute all three notebooks with visible real outputs and include their imported source modules.
- [ ] Save final selected model weights for GPT, all three sentiment models, and CycleGAN.
- [ ] Complete every required metric; resolve entries marked unavailable or explain permitted limitations.
- [ ] Write three real GPT failure analyses and the requested sentiment error review.
- [ ] Obtain and score two independent human GAN ratings on the agreed fixed inputs.
- [ ] Verify own-model direct inference and the actual Kaggle export/submission.
- [ ] Compare all team members using the common protocol; add member `results.md`, `failure_analysis.md` and metrics CSV to the shared repository.
- [ ] Finish combined `Report.pdf`, including the GitHub URL, approaches, architecture, parameters, results and limitations.
- [ ] Build one final ZIP with Part 1/Part 2/Part 3, executed notebooks, saved weights, required outputs and the combined report. The preparation ZIP is not a final submission.
- [ ] Reopen the final ZIP and notebooks; check completeness and Canvas size limits/deadline (screenshot: October 6, 6 PM).
