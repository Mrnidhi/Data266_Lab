AUDIT SCORING (CPU ONLY; RUN AFTER BOTH HUMAN SHEETS ARE COMPLETE)
Use a project-compatible Python environment (Python >=3.12; dependencies in
pyproject.toml). Check the lab environment first instead of replacing its CUDA
stack. The existing audit command imports torch, numpy, Pillow and common
utilities, but performs no model inference and needs no GPU or checkpoint.
For a prepared environment, from the repository root on Linux/macOS:

PYTHONPATH=src python -m lab1.cyclegan audit-score --rater-one runs/part3-human-review-20260929/rater_1.csv --rater-two runs/part3-human-review-20260929/rater_2.csv --output-dir runs/part3-human-review-scored

Replace the CSV paths with the user's current files if stored elsewhere, and
use a new output folder if that output already exists. With an editable project
installation, the PYTHONPATH prefix is unnecessary (including on Windows).
This writes human_agreement.json with mean scores, exact percentage agreement,
and quadratic weighted Cohen's kappa for each criterion, pooled and per direction.
The command rejects blanks and mismatched sample sets. Kappa may be undefined
when expected disagreement is zero; report that honestly, not as 0 or 1.
