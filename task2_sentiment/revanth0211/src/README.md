# Source

[Part2.ipynb](Part2.ipynb) is the canonical executed notebook and the only
submitted source notebook. It contains environment capture, deterministic
data selection, training-only vocabulary construction, all three model
implementations, checkpointed training, full test evaluation, bootstrap
intervals, calibration metrics, paired McNemar tests, robustness slices,
plots, the completed 20-case error review, and final interpretation.

Run it from this directory or the parent member directory so relative paths
resolve correctly. A full rerun rewrites files under `../checkpoints/` and
`../outputs/`.
