# Source

[Part1.ipynb](Part1.ipynb) is the canonical executed notebook and the only
submitted source notebook. It contains environment capture, TinyStories
loading, disjoint sampling, character vocabulary creation, manual causal
attention, the GPT model, training and checkpoint selection, full evaluation,
generation, saved-artifact checks, and the completed three-case failure
analysis.

Run it from this directory or the parent member directory so its relative
paths resolve correctly. A full rerun rewrites files under `../checkpoints/`
and `../outputs/`.
